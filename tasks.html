Практическая работа 1: рисунок на CSS

Трактор нарисован только с помощью HTML и CSS. Каждая деталь - отдельный блок с position: absolute внутри рамки 200 на 200 пикселей. Солнце сделано радиальным градиентом, крыша и корпус - через clip-path, а колёса - с помощью псевдоэлементов ::before и ::after.

Практическая работа 2: анимированный ролик

Анимированный баннер без JavaScript. При наведении мальчик ищет мяч, а при нажатии оказывается, что он пнул кирпич. Кадры переключаются через opacity, а движение сделано с помощью @keyframes. Наведите курсор или нажмите на картинку.
